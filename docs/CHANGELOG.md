# Changelog

## v1.15.0（2026-10-20）

**Pearl Glass Gallery 全局视觉升级。**

- 主界面改为珍珠白底、冷青/暖粉环境光和高通透白色卡片；移除旧背景图对内容的干扰。
- 顶部导航、二级分类、视频卡、搜索框、搜索词、个人中心与设置统一焦点语言：深色外描边、粉色内沿，当前栏目与遥控器焦点可同时辨认。
- 视频封面保持 100% 原始色彩与不透明度，不再叠加白色雾层；直播卡新增 `LIVE` 标识，排行榜卡新增名次标识。
- “我的”与账号/设置二级页改为统一白色面板；设置行使用真实滑块位置和颜色表达开关状态；登录/错误空态缩小并补充主操作按钮。
- UP 主主页和图文动态详情从旧深色列表升级为 Pearl Glass 浅色内容页；UP 投稿卡支持焦点缩放、深色聚焦面与粉色描边。
- 搜索输入弹层同步改为明亮主题，输入框使用高对比粉色描边，不再出现与搜索页割裂的旧深色弹层。
- 直播、动态、收藏、排行榜补充独立状态徽标；直播结果稀少时使用更大的展示卡，避免大屏只剩一个小缩略图。
- 实测搜索历史词返回 20 条结果，首条可进入原生详情并成功取得视频地址播放，未再出现“无法获取视频地址”。
- 十英尺可读性优化：放大顶部导航、页面标题、二级分类、卡片标题与作者信息；卡片焦点缩放幅度加大，滚动后仍保持完整描边和正确行定位。
- 扫码登录页重构为深色影院玻璃面板，强化二维码、步骤和刷新操作的视觉层级。
- 视频详情页统一品牌粉并强化播放主按钮、UP 行、推荐卡焦点；播放器功能按钮缩为进度条上方的横向图标组，保留 OK 进入弹幕/倍速/清晰度二级菜单的交互。
- 网页兜底页增加原生 TV 工具栏、返回/刷新按钮与 MENU 聚焦入口，网页正文放大并注入遥控器焦点描边，避免偶发网页路由退回裸 WebView。
- 启动画面改为与 Pearl Glass 一致的珍珠白、冷青与暖粉渐变，Android 12 及以上使用系统 SplashScreen 品牌图标。
- 效果图对齐第二轮：删除主内容页多余的大标题区，顶部导航和分类栏按效果图比例重排；视频画廊由四列小卡改为三列大卡，首张卡使用主视觉宽卡结构。
- 视频详情按效果图重构为可见的全屏封面氛围背景，放大右侧封面、标题、操作按钮和推荐卡；搜索落地页改为横贯页面的大搜索框。
- 动态页改为专用信息架构：接口补充真实作者头像与发布时间，页面增加关注头像横栏、更新红点、主视觉宽卡、普通动态卡及图文动态样式；遥控器焦点可在三列动态卡间移动。
- 登录态“我的”完成同状态实机复核，保持账号资料侧栏、六项菜单和三列历史画廊；搜索结果网格调整为四列，以接近效果图的三条视频 + 一条番剧/影视侧卡结构。
- 修正效果图焦点语义：移除所有列表“第一张永久大卡”，推荐/热门/排行/动态/收藏/搜索/个人内容默认均为等宽等高；仅当前遥控器焦点卡放大约 6%，焦点移动后原卡恢复、新卡放大，并最后绘制避免描边被相邻卡遮挡。
- UP 主页、视频详情推荐/选集以及播放器底部推荐/分P/剧集卡同步采用“默认等大、焦点放大”的统一规则。
- 搜索结果不再共用单一视频卡：视频/直播间使用横版封面卡，番剧/影视使用六列竖版海报卡，主播/用户使用三列头像资料卡；“全部”结果按真实类型显示视频、影视、直播等徽标。
- 搜索结果遥控器导航会随当前类型自动切换为 4/6/3 列，焦点卡单独放大；实机验证用户卡可进入 UP 主页，视频结果可直接取得地址并播放。
- “我的”资料区补充冷青到暖粉的 Pearl Glass 横幅、放大头像压边、等级/VIP 和三项账号统计，左侧菜单与右侧三列历史画廊保持同屏。

- 动态画廊新增「视频 / 图文 / 专栏 / 转发 / LIVE」类型徽标；文字和转发动态使用正文卡与原动态入口，焦点放大仍只作用于当前卡片。

- “我的”四类内容列表补充专用状态表达：历史记录显示观看进度条，收藏、稍后再看、追番分别显示「收藏 / 待看 / 追番」徽标；各页仍保持默认等大、仅焦点卡放大。

## v1.14.2（2026-10-18）

**弹幕可读性与流畅度优化。**

- 字号 dp(22) → dp(34)，描边 dp(4) → dp(6)，行高 dp(58) → dp(64)，8 条通道；可见上限 36 → 28。
- 平滑移动：新增 SystemClock 锚点按倍速外推，小偏差（<600ms）分帧缓动吸收（约 0.3s 对齐），seek/暂停/缓冲/切P/切集/清晰度才重锚，避免前后抖动。
- 帧率：overlay 由 30fps（postInvalidateDelayed 33）改为 `postInvalidateOnAnimation`，播放中目标 60fps；无弹幕或暂停时停止重绘。
- 性能：弹幕文字预渲染 Bitmap（描边+填充）LRU（8MB 上限），每帧只 drawBitmap，不再每帧 measureText/双 drawText。
- 验证：字号明显变大、密集弹幕可读性提升、播放/seek 后弹幕正常。证据 `qa/v1.14.2/`。
- `clean assembleDebug lintDebug` → BUILD SUCCESSFUL，Lint 0 errors / 23 warnings。

### 说明

- 模拟器为 swiftshader 软件 GPU，帧率统计偏低，不代表真机；真机目标 60fps。
- 弹幕通道仍按索引分配，未做严格碰撞避让；如仍觉得拥挤可以再调密度/行数。

## v1.7.1（2026-10-18）

**修复弹幕开关打开但屏幕无弹幕的问题。**

- 根因：`comment.bilibili.com` 固定返回 `Content-Encoding: deflate`（raw deflate），Android `HttpURLConnection` 只透明解压 gzip，不处理 deflate，导致 XML 解析失败并静默返回空弹幕列表。
- 修复：弹幕请求按 `Content-Encoding` 手动解压（deflate 用 `Inflater(true)`，gzip 用 `GZIPInputStream`）；单条脏数据不再导致整集弹幕丢失；弹幕按时间排序。
- 验证：番剧与普通视频在模拟器上均能正常显示滚动弹幕；证据 `qa/v1.7/danmaku-*.jpg`。
